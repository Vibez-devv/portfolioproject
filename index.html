MY NOTE APP

Store your thoughts before you forget them.....

I built my Note App using HTML, CSS, and JavaScript to improve my web development skills and learn how to create interactive websites. I first used HTML to build the structure of the application, including a title, an input field, an add button, and a section to display notes. I then used CSS to design the interface by adding colors, spacing, borders, and shadows to make the application neat and attractive. I also used Flexbox to arrange the notes properly and make the layout user-friendly. To add functionality, I used JavaScript. I created functions that allow users to add, edit, and delete notes. I also used event listeners to handle button clicks and user interactions. To prevent data loss after refreshing the page, I saved the notes in the browser's Local Storage. This project improved my understanding of HTML, CSS, JavaScript, DOM manipulation, and Local Storage while helping me build a practical and useful web application.

DIGITAL OCEAN

Deep Ocean

**My DigitalOcean Project** As part of my training at SQI College of ICT, I completed a project using DigitalOcean to learn about cloud hosting and web deployment. The goal of the project was to understand how websites and web applications are hosted on the internet. I created a virtual server, connected to it securely, and configured the environment needed to run my application. Completing this DigitalOcean project at SQI College improved my technical skills, increased my confidence in cloud technologies, and prepared me to handle future web hosting and deployment tasks.
